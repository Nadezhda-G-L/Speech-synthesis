## 1. Краткий итог работы

В рамках лабораторной работы были обучены две акустические модели FastSpeech2 для синтеза русской речи:

1. `baseline_gt` - модель, обученная на ground-truth фонемной разметке корпуса RUSLAN;
2. `baseline_g2p` - модель, обученная на G2P фонемной разметке, полученной с помощью модуля G2P из лабораторной работы №3.

В качестве вокодера использовался Griffin-Lim.

Итоговый результат:

- обе модели успешно заговорили;
- речь стала различимой, слова воспроизводятся фонетически корректно;
- MCD моделей ниже MCD baseline-модели, предсказывающей среднюю mel-рамку;
- диапазон мела у синтезированных моделей сопоставим с оригинальным;
- отношение числа кадров составляет около `0.92–0.94`, то есть синтезированная речь немного короче оригинальной;
- G2P-модель по метрикам почти не уступает GT-модели, но имеет меньшее отношение длительности;
- основная проблема звучания - механический/роботизированный окрас.

## 4. Обоснование выбранной скорости обучения

Была выбрана скорость обучения:

```python
lr = 1e-3
```

Обоснование:

1. `lr = 1e-4` является значением по умолчанию, но для данной задачи такое обучение слишком медленное.
2. `lr = 5e-3` быстрее приводит к речеподобному звуку, но повышает риск нестабильности и расхождения.
3. `lr = 1e-3` является компромиссным значением:
   - модель успешно сходится;
   - речь появляется за разумное время;
   - training/eval метрики устойчиво улучшаются;
   - обучение остаётся управляемым.

## 10. Оценка мелодического качества

Мелодическое качество получилось ограниченным.

В текущих запусках использовались:

```python
use_pitch = False
use_energy = False
```

То есть модель не обучала явно:

- высоту основного тона;
- энергетические акценты;
- фразовую интонацию;
- просодические переходы между словами.

Следовательно, ожидаемые проблемы:

- относительно монотонная речь;
- слабая выразительность;
- мало выраженные акценты;
- паузы чуть короче;
- дополнительно добавлен металлический окрас.

## 12. Что осталось неудачным

### 12.1. Высокий абсолютный MCD

MCD около `29 dB` формально является высоким.

Возможные причины:

- Griffin-Lim вносит сильные фазовые и спектральные артефакты;
- DTW-выравнивание может быть нестабильным при ошибках длительности;
- модель может сглаживать спектральную деталь оригинала;
- MCD не всегда согласуется с субъективной intelligibility.

### 12.2. Роботизированный окрас речи

Это самая заметная проблема на слух.

Основные гипотезы:

1. Griffin-Lim плохо восстанавливает фазу.
2. Отсутствуют pitch- и energy-предикторы.
3. Модель не использует явные просодические признаки.
4. Обучение шло ограниченное время, мало эпох.

### 12.3. Речь короче оригинальной

GT-модель имеет duration ratio:

```text
0.942
```

G2P-модель:

```text
0.915
```

Гипотезы:

- internal aligner может сжимать паузы;
- G2P-разметка может изменять локальную структуру токенов;
- отсутствие pitch/energy влияет на распределение длительности;
- Griffin-Lim может усиливать восприятие сжатой речи.
